## Why these fonts (one-line each)

**Alfa Slab One** — Matches the slab-serif character of the VPP logo wordmark. Heavy, substantial, craft-forward. The logo IS slab serif; the display font must reinforce, not contradict.

**Inter** — Industry-standard humanist sans designed for screen readability at every size. Pairs cleanly with slab serif because the contrast is intentional: heavy display, neutral body.

---

## Hard rules (full list in `vpp-typography-spec.md`)

- Never use Alfa Slab One below H3 (24px) — becomes unreadable
- Never stack Alfa Slab One in three-line headlines — cap at two
- Never mix in additional display or body fonts — two-typeface system, full stop
- Never use script fonts anywhere
- Headlines never use the same weight as CTAs — natural hierarchy
